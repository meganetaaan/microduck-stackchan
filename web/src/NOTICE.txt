MicroDuck Tab5 Lab
Independent browser-only MuJoCo WASM / ONNX Runtime Web simulator, October 2026.
Not an official Pollen Robotics or Hugging Face release. No physical robot is connected.

IMPORTANT: This is a mixed-license application. Software and trained weights are
not licensed the same way as the MicroDuck-derived robot geometry.
