# フラップ腕：薄型とゴツめの3案

前回の④側面フラップ腕を基準に、丸みを残した太めの外装を2段階追加しました。実際の3Dメッシュによる静止シルエット比較です。

- **A：元の薄いフラップ**。前回④と同じ形状・色・取付位置
- **B：丸い装甲付き**。厚みのある縁、丸い先端、少し太いヒンジ。コンパクトさを残す中間案
- **C：さらにゴツい装甲付き**。厚い本体、太い上下の縁、丸い大きな先端。より腕らしい塊感を重視

比較画像は同じ機体、縮尺、カメラ、開き角です。顔、Tab5、胴体、MicroDuckの脚は共通です。開いた状態ではヒンジを左右60度とし、収納イメージでは側面に沿わせています。

## 3Dと再生成

`glb/`に3案×2姿勢の全身GLBがあります。画面の画像も埋め込み済みです。GLBはメートル・Y-up・前方+X、ソースMJCFはメートル・Z-up・前方+Xです。静止メッシュであり、可動リグやアニメーションはありません。

Python 3.12で依存パッケージを用意し、`python build_chunky_flaps.py`を実行すると全モデルと画像を再生成できます。ソースZIPにベースモデルと必要資産を含むため、元のプロジェクトを別に取得する必要はありません。

`build_chunky_flaps.py`の`build()`にB・Cの形状、厚み、色と姿勢があります。`geometry_tools.py`は丸角形状作成、前回の基準モデル、静止レンダー、GLB出力の共通処理です。描画はMuJoCo 3.10.0を使用し、Linuxヘッドレス環境ではEGLを使います。

## 配布ZIP

各ZIPは通常の独立したZIPで、19MB未満です。

1. `Chunky_Flap_Arms_01_Source_and_Images.zip`：再生成ソース、全資産、比較画像4枚、検証記録。このZIPだけで再生成できます
2. `Chunky_Flap_Arms_02_Display_GLB.zip`：A・B・Cの開いた姿勢。GLBだけを見るならこのZIPのみで利用できます
3. `Chunky_Flap_Arms_03_Stowed_GLB.zip`：A・B・Cの収納姿勢

3つを同じ場所に展開すると、共通の`Chunky_Flap_Arm_Concepts_v1`フォルダにまとまります。重複するREADMEは同一内容です。共通フォルダの内側へさらに展開すると階層が二重になるので注意してください。

## 確認したこと・未検証のこと

6シーンの読込・静止レンダー、6GLBの再読込・画面テクスチャ、ZIP整合性を確認しています。比較画像の実際の画素も確認しました。Aの元形状を保持し、前回の成果物・採用アセンブリ・歩行モデル・公開シミュレータは編集していません。

これは見た目を選ぶためのコンセプトです。ヒンジや装甲の外観は、実際のサーボ・固定方法・強度が成立していることを意味しません。質量・慣性、配線、衝突、しゃがみ・座り・脚の折り畳み、印刷可能性、歩行は未検証です。描画専用MJCFは衝突形状を省略し、追加の腕は無質量・非接触にしています。学習や制御、物理性能評価には使わないでください。
