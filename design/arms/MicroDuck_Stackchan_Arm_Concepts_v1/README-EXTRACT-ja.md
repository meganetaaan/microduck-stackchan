# ZIPの展開方法

この成果物は、1添付あたり20MB未満に収めるため3つの独立したZIPに分けています。分割アーカイブ形式ではないため、それぞれ普通のZIPとして開けます。

- `MicroDuck_Arm_Concepts_01_Source_and_Images.zip`：全4案の編集・再生成ソース、全メッシュ資産、比較画像4枚、検証記録
- `MicroDuck_Arm_Concepts_02_GLB_Options_1_2.zip`：①短いパドル腕と②折り肘腕の全身GLB。各案に展示・収納の2姿勢
- `MicroDuck_Arm_Concepts_03_GLB_Options_3_4.zip`：③ミトン腕と④側面フラップ腕の全身GLB。各案に展示・収納の2姿勢

まとめて利用する場合は、3つを同じ場所へ展開し、共通の`MicroDuck_Stackchan_Arm_Concepts_v1`フォルダを結合してください。このフォルダの中へさらにZIPを展開すると階層が二重になるので注意してください。重複するREADMEは同一内容です。

GLBだけを見る場合は②または③のZIPだけでも利用できます。各GLBは全身形状と画面テクスチャを内包しています。ソースを編集して全案を再生成する場合は①のZIPだけで足ります。

静止したシルエット検討用モデルです。可動機構、印刷、干渉、質量、歩行は未検証です。採用済みアセンブリと歩行モデルは更新していません。
