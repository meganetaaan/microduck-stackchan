## 最新結果：専用10軸方策の学習と評価

このアセンブリの物理モデルを固定したまま、公開方策を初期値とする39観測・10出力の専用方策をCPU PPOで768,000制御ステップ、MuJoCoによるコマンド校正で105,600ステップ追加学習しました。実行時に旧14出力方策を呼び出すアダプターは使用しません。

静止、低速前進、前進、後退、左右移動、左右旋回の8モードで、定常試験112 / 112、60秒の連続切替5 / 5が定義した基準を通過し、転倒・胴体と脚の接触は0でした。ただし精密な経路追従を保証する基準ではなく、後退の20秒試験では質量・電圧・摩擦を変えた条件で横ずれが最大約0.722 m残っています。実機試験、座り立ち、SIT/FOLD制御、転倒復帰は対象外です。

条件・基準・方策・動画・再現手順は別添の[歩容学習成果物](training/tab5_gaits/README.md)を参照してください。学習ZIPをプロジェクトのルートへ展開すると、ZIP内の`training/tab5_gaits/`が正しい場所に統合されます。`training/tab5_gaits/`の内側へZIPを展開しないでください。このアセンブリZIPには学習成果物を重複収録していません。旧版READMEのゼロショット試験や「再学習なし」は過去の結果です。

## アセンブリの構成

採用済みの縦型Tab5と前面フラット接触部を維持し、基板、電源分岐部、UART配線、固定部品を含むアセンブリへ更新しました。主案は3.3 V UART直結です。Tab5はUI、MicroDuckのSoCは歩行制御を担当し、Tab5の電源は機体の保護・主スイッチ後の2S系統から別経路で供給する仮構成です。

実機がないため、部品の寸法には公式値、公式CADからの抽出値、配置用の仮形状が混在します。HAT、コネクタ、保護部品、線材、ねじの実物適合はまだ確定していません。この区別は[部品表](docs/BOM-ja.md)と[設計前提](docs/DESIGN-ASSUMPTIONS-ja.md)に記載しています。

## 今回追加したもの

- Radxa ZERO 3Wの65 ×30 ×1.6 mm基板、公式CADで確認した4つの直径2.8 mm穴、40ピンヘッダーの配置
- 実寸未確認のRobot HATと部品群を表す別の仮形状と質量。Radxa単体だけで必要部品が収まったとは扱わない
- 基板を支える取り外し可能なプリント製キャリア、M2.5固定具、ボディ側のM2固定具
- 電源分岐・保護部の仮配置、交換可能なピッグテール接続部、Tab5側のJ7とM5-Busの差込部
- 赤の電源線、青のUART線、グロメット、キャリアと一体の配線ガイド
- 実際に空いた電源貫通穴と、Tab5裏のM5-Bus差込部を避ける前面下側の逃げ

外側80 ×80 ×80 mm、Tab5位置、カメラ上向き、画面上半分の顔、元の脚・関節・サーボ位置は維持しています。配線やねじをプラスチックの中へ重ねて見せる代わりに、必要な穴と頭逃げを実体形状へ反映しています。

## 印刷部品

`prototype/assembly_uart/stl/`には以下の5部品をmm単位で保存しています。`stl_print_oriented/`にはZ=0に置いた参考の印刷向きも用意しています。キャリアの基台と保護トレーは底面側を置く想定ですが、支持材や印刷条件は未検証です。

1. ボディケージ。前面差込部の逃げ、電源貫通穴、M3頭逃げを追加
2. 中央マウント。上部固定用のM2ナット逃げを追加
3. 電子部品キャリア。Radxa穴位置に対応した支持部と配線ガイドを含む
4. 電源保護部の仮トレー
5. 背面カバー。前版と同一

グロメット、ケーブル、コネクタ、基板、ねじは印刷部品には含めません。キャリアの配線ガイドは保持力を実測したクランプではなく、部品・印刷公差に合わせた追加固定が必要になる可能性があります。保護モジュールのトレー・接着支持も仮構成です。

## 質量と重心

標準モデルは736.537 gで、前の外装主体のモデルから35.068 g増えています。同一STAND姿勢の重心は、前方へ0.642 mm、左右方向へ−0.109 mm、上方へ3.741 mm移りました。脚とTab5の質量は変更していません。

電装・配線・未確定小部品の仮定を変えたモデルは717.815〜767.712 gです。この範囲は計測結果や確率分布ではありません。元の機体とTab5、樹脂の密度は固定し、明示した未確定部品の質量・慣性だけを変えています。詳細は`mass_scenarios.json`と`mass_COM_comparison.json`を参照してください。

## 干渉確認と限界

保存済みの姿勢遷移303状態と、足裏を接地したしゃがみ候補181状態、計484状態を確認しました。追加アセンブリと34個の脚の衝突判定形状の接触はありませんでした。中央マウント付近の最小距離の数値下限は3.333 mm、配線と内側の電源接続部は26.202 mmです。

固定された元のCADとの実体重なりはなく、アセンブリ内部にも未解決の実体重なりはありません。ケーブルが指定のコネクタ端末に入る7箇所は意図した接続として区別しています。5つの印刷STLはすべて単一で閉じた実体です。公式Radxa CAD全体を覆う追加の保守的な衝突外形も備えています。

これらは保存した状態での幾何確認です。実機適合、全ての連続姿勢、配線の柔軟な変形、端子の抜け、印刷強度、回路の定格を検証したものではありません。電源ピッグテールの機体側終端は、分岐位置未確認のため仮の受け渡し位置です。元のSIT姿勢の床への約4.441 mmの入り込みと、FOLDの元の脚同士の8件の保守的な判定も残っています。

`validation_report.json`に幾何検証の範囲と結果を保存しています。ここに書いた484状態の確認と、冒頭で示した動的な歩容評価は別の検証です。歩行・横移動・旋回の条件と成否は、[学習結果の評価と動画](training/tab5_gaits/README.md)を参照してください。

## 再現

既存の取得・環境構築手順は、公式のMicroDuck資産とCPU用依存関係を固定版から取得します。

```sh
bash bootstrap_assembly_uart.sh
MUJOCO_GL=egl .venv/bin/python prototype/assembly_uart/render_assembly.py
.venv/bin/python prototype/assembly_uart/validate_assembly.py
```

原典のRadxa CADは再配布せず、出典と抽出した外形を同梱しています。原典メッシュがない環境では検証スクリプトは保存済みの公式CAD外形を使い、その区別を報告します。原典からの再抽出は別途公式資料を取得してください。

各部品の寸法・配置・質量は`build_assembly.py`の部品定義を編集します。`parameters.json`は構成メモで、`mass_scale`は生成処理に適用していません。質量感度は`make_mass_scenarios.py`で扱います。形状や質量を変更した場合、学習済みモデルのハッシュと一致しなくなるため、再度の干渉確認と評価が必要です。

既存のONNX推論を利用する場合は、必ず`ORT_DISABLE_TELEMETRY=1`をプロセス起動前に設定する`prototype/portrait/run_local_probe.py`を使用します。新しい歩容の学習・評価手順は学習側の資料に従ってください。実機に接続・書き込み・制御するスクリプトはこのアセンブリ作業には含めていません。
