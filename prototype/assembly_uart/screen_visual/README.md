# Tab5の画面：ｽﾀｯｸﾁｬﾝの顔とロボットパネル

添付見本を実際に確認し、上半分の顔を「小さな白い丸目2つ＋短く角の丸い水平の口」として描き直しました。写真の画素は加工していません。ベクター図形から生成した、編集できる画面用アートです。

下半分は、MicroDuckの脚の白い外装、グレーの機構部、オレンジの足に合わせたロボットパネル柄です。丸みのある大きな面、控えめな溝、オレンジのアクセントに絞りました。実際のメーターやスイッチではなく、追加の物理部品でもありません。

## ファイル

- `assets/stackchan_microduck_screen_720x1280.png`：カメラ上向きの縦画面、ネイティブ解像度720 ×1280 px
- `assets/stackchan_microduck_screen.svg`：編集可能なベクター原稿
- `scene_tab5_assembly_uart_screen.xml`：全身のMuJoCo表示用シーン
- `tab5_assembly_uart_screen.xml`：画面の見た目だけを更新したモデル
- `upper_assembly_screen.glb`：テクスチャを埋め込んだ上部アセンブリ。単位m。元のMicroDuckの脚CADは含めず、全身はMJCFで確認
- `screen_robot_views.png`：機体全体の正面・側面・斜め図
- `screen_closeup.png`：画面と外装の拡大図
- `build_screen.py`、`render_screen.py`：画像・MJCF・GLB・プレビュー生成コード
- `validation/`：表示変更と物理モデルの互換性検証

上半分はピクセルY=0〜639、下半分はY=640〜1279です。Tab5公式仕様は横向き1280 ×720 pxで、ここでは縦向き720 ×1280 pxにしています。参照：[M5Stack Tab5公式仕様](https://docs.m5stack.com/en/core/Tab5)。実機画面への転送やファームウェアへの組み込みは、このアート作成には含めていません。

## 物理モデルと学習結果

学習に使った親フォルダの`tab5_assembly_uart.xml`、3つの質量モデル、参照メッシュを上書きしていません。固定済み1,654ファイルのハッシュを検証します。表示用XMLは別のハッシュを持つため、学習モデルと同一ファイルだとは扱いません。

MuJoCo 3.10.0による互換性検証は合格しました。質量736.537 gと各部の慣性、1,687個の形状ID、1,597個の接触形状、53,992組の明示接触ペア、関節・アクチュエータ・センサーの順序が一致します。5つの状態で前進動力学と接触の比較差は0でした。これは見た目の変更が物理計算を変えないことの確認で、歩行試験を追加実行した結果ではありません。詳細は`validation/physics_compatibility_report.json`にあります。

表示変更は、既存の無質量・非接触の`screen`を同じ外寸のUV付きメッシュへ置き換え、古い水色の目を透明にしただけです。Tab5の寸法・位置・カメラ、機体の質量・慣性、関節・モータ、衝突判定、観測順序を維持します。画面の新しい絵柄のために歩容を再学習する必要はありません。従来の歩行評価は保存した物理モデルに対する結果であり、新しい実機適合や経路追従性能を保証するものではありません。

学習とランダム化を使う再評価では、引き続き親フォルダの固定済みシーンを指定してください。学習コードはシーンと同じフォルダにあるlight/heavyモデルから部品ごとの質量範囲を取得します。この画面用サブフォルダを代わりに指定すると、別の質量ランダム化にフォールバックするため、保存した評価条件の再現にはなりません。学習ZIPと以前の歩行動画は変更していません。

## 再現

まずプロジェクトの`bootstrap_assembly_uart.sh`で固定版の元資産と環境を用意します。画面生成にはInkscapeのSVG→PNG変換機能も使います。プロジェクトのルートで実行してください。

```sh
.venv/bin/python prototype/assembly_uart/screen_visual/build_screen.py
.venv/bin/python prototype/assembly_uart/screen_visual/render_screen.py
```

静止画生成では重い衝突判定資産を外した一時的な描画専用モデルを使います。このモデルを歩行評価には使いません。配布する表示用MJCFは元の接触・重力・有限モータ設定を維持した完全モデルです。PNGを直接Tab5へ表示する場合も、画像の上辺がカメラ側となるように配置してください。
