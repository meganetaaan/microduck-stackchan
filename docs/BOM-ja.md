# MicroDuck Stack chan UARTアセンブリの暫定部品表

更新日 2026年10月2日

主案は、Tab5をUIとして使い、MicroDuckのSoCへ3.3 V UARTで指示を送る構成です。Tab5は機体の保護・主スイッチ後の2S系統からHVINへ給電します。USB-UARTは直結できない場合の代替案であり、両方を常設する部品表ではありません。

実機がないため、購入・配線仕様を確定していない部品は明記しています。以下の形状・重量は`prototype/assembly_uart/`のモデルに対応します。

## UART接続の選択

| Tab5側 | 接続 | MicroDuck SoC側 |
| --- | --- | --- |
| M5-Bus物理pin 16、GPIO6、UART TXとして設定 | → | Radxa 40ピン物理pin 16、UART4 RX_M1 |
| M5-Bus物理pin 15、GPIO7、UART RXとして設定 | ← | Radxa 40ピン物理pin 18、UART4 TX_M1 |
| GND | 共通 | GND |

物理ピン番号とGPIO番号を混同しません。使用するRadxaのGND端子は実物の接続しやすさと既存HATを確認して決めます。5 Vや3.3 Vの給電線を、この信号3本の代わりに接続しません。OSのUART有効化、Tab5のピン設定、HATとのピン共用は未確認です。

Tab5の図面表記`M3*10`を10 mmの挿入許容深さと読み替えません。M3の頭逃げや各プリント部の局所的な薄肉について、試し刷りと強度確認が必要です。
