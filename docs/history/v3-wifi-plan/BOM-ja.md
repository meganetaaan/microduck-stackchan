# MicroDuck Stack chan 縦型Tab5案の暫定部品表

更新日 2026年10月2日

実機が手元にない段階で、選定済みの縦型Tab5・前面フラット接触部の設計を進めるための部品表です。外装形状は現在のモデルを維持し、電源・通信・取付部品は確認できた範囲と仮置きを分けています。この表だけで発注や実機への配線を確定しません。

## 今回の仮置き

- Tab5は画面・顔・操作UIを担当し、MicroDuckのSoCが歩行制御を担当する
- 電源はMicroDuckの保護・主電源スイッチ後の2S系統から分岐し、Tab5のExtPort2 J7へ供給する構成を第一案とする
- Tab5の内蔵降圧回路を使い、外付け降圧器とTab5用の別バッテリーは第一案に含めない
- 通信はWi-Fiで指示と状態を交換する。本試作のTab5連携API、接続方式、通信断時の挙動は未実装・未確定
- ロボット側の電源接続は交換可能な短い変換ハーネスにし、コネクタが判明するまで専用の外装穴を固定しない

詳細は[設計前提と確認項目](DESIGN-ASSUMPTIONS-ja.md)を参照してください。

J7はpin 1がGND、pin 2がSYS_VIN（製品表記HVIN、6–24 V）です。pin 3/4のRS485 A/B、pin 5/6のSDA/SCLは第一案では使用しません。配線の向きは公式ピン図と実物を照合し、ケーブルの色だけで判断しません。これは結線方針であり、実機に適用する確定配線図や通電手順ではありません。[S1][S2][S3]

Radxa ZERO 3WのUSBホスト出力は資料上500 mAです。Tab5を十分に給電できるとは仮定しません。また、普通のUSBケーブルを「データ専用」とは扱いません。外部電源とUSBを併用する場合は、双方の電源経路を確認する必要があります。[S4]

背面カバーの頭逃げは直径4.2 × 深さ1.0 mmです。F01の薄い仮頭形状を理由に、未確認の標準ねじを発注しません。ソースの`rear_nut_pocket_depth_mm=1.9`は現生成処理で使われておらず、実際のナット穴深さは2.0 mmです。今回は形状を変更していません。
